## [v0.1.0] - 2025-08-19

### Added

- CLI with word, segment, dictionary, context, setup, and fetch commands
- Dictionary building from Kaikki/Wiktextract JSONL with compact sense storage in SQLite
- FrequencyWords-based word list fetching and caching with provenance metadata
- Candidate-aware context evidence with topic_scores and supports for semantic topic matching
- Vendoring tools for offline word lists and dictionary indexes
- Lexicon with contains, rank, and segment for compact identifiers and domain labels
- Lazy on-demand dictionary fetching with fetch_missing=True and --offline CLI flag
- Zero runtime dependencies with Python 3.10+ support
